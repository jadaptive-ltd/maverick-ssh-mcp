Interactive Persistent TTY Support

SFTP Operations

Random access file operations, directory traversal, and full SFTP protocol support for seamless file management across your fleet.

Random Access Dir Traversal Full Protocol

SSH Teams

Deep integration with SSH Teams for passwordless, device-level security using hardware-backed certificates and zero-trust principles.

Passwordless Zero Trust Cert Auth

TCP Tunnels

Local and remote TCP port forwarding for secure tunneling. Expose services or reach internal resources through encrypted channels.

Local Forward Remote Forward Encrypted

Bind and forward Unix Domain Sockets for inter-process communication over SSH. Access local sockets remotely as if you were on the host.

Bind Forward IPC Over SSH Local Socket

maverick-config.json 
{
  "maverick": {
    "server": "ssh://maverick.local:8000",
    "teams": {
      "enabled": true,
      "mode": "passwordless"
    }
  },
  "connections": [
    {
      "alias": "prod-web-01",
      "host": "10.0.1.50",
      "port": 22,
      "methods": [
        "shell",
        "sftp",
        "tunnel-local"
      ]
    },
    {
      "alias": "db-cluster-01",
      "host": "10.0.2.100",
      "port": 22,
      "methods": [
        "sftp",
        "tunnel-remote",
        "uds-forward"
      ]
    }
  ]
}}
